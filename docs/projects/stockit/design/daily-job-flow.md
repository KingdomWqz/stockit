# 每日数据任务逻辑流程

本文档只描述每日股票数据任务的逻辑流程，不绑定具体代码文件、函数名或调度实现。

## 1. 总体流程

```text
开始
 |
 v
+----------------+
|  准备运行环境  |
|  - 数据库可用  |
|  - 表结构可用  |
+-------+--------+
        |
        v
+----------------+
|  同步基础数据  |
|  - 股票列表    |
|  - 交易日历    |
|  - 行情基础项  |
+-------+--------+
        |
        v
+----------------+
|  采集行情数据  |
|  - 当日行情    |
|  - 历史 K 线   |
|  - 成交量价    |
+-------+--------+
        |
        v
+----------------+
|  数据标准化    |
|  - 字段归一    |
|  - 缺失处理    |
|  - 去重覆盖    |
+-------+--------+
        |
        v
+----------------+
|  二次计算      |
|  - 技术指标    |
|  - K 线形态    |
|  - 统计特征    |
+-------+--------+
        |
        v
+----------------+
|  策略筛选      |
|  - 买入候选    |
|  - 卖出候选    |
|  - 策略信号    |
+-------+--------+
        |
        v
+----------------+
|  回测验证      |
|  - 后续收益    |
|  - 胜率统计    |
|  - 风险指标    |
+-------+--------+
        |
        v
+----------------+
|  闭盘后补充    |
|  - 财务/资金   |
|  - 排名/榜单   |
|  - 稳定数据    |
+-------+--------+
        |
        v
+----------------+
|  清理与收尾    |
|  - 过期数据    |
|  - 任务日志    |
|  - 运行状态    |
+-------+--------+
        |
        v
       结束
```

## 2. 数据依赖关系

```text
基础数据
|
+--> 股票列表
|
+--> 交易日历
|
+--> 市场基础行情
|
`--> 个股历史 K 线
     |
     v
二次计算
|
+--> 均线
|
+--> MACD / KDJ / RSI / BOLL
|
+--> K 线形态
|
`--> 量价统计特征
     |
     v
策略筛选
|
+--> 指标买入信号
|
+--> 指标卖出信号
|
+--> 形态信号
|
`--> 自定义策略信号
     |
     v
回测验证
|
+--> 信号后 N 日收益
|
+--> 最大回撤
|
+--> 胜率 / 盈亏比
|
`--> 策略有效性评估
```

## 3. 分层视图

```text
+--------------------------------------------------+
| 数据源层                                          |
| 股票列表 / 交易日历 / 实时行情 / 历史 K 线 / 财务 |
+-----------------------+--------------------------+
                        |
                        v
+--------------------------------------------------+
| 基础数据层                                        |
| 清洗、去重、标准化、入库、维护 active 状态         |
+-----------------------+--------------------------+
                        |
                        v
+--------------------------------------------------+
| 指标特征层                                        |
| 技术指标、K 线形态、量价特征、趋势强弱             |
+-----------------------+--------------------------+
                        |
                        v
+--------------------------------------------------+
| 策略信号层                                        |
| 买入候选、卖出候选、策略命中、组合候选             |
+-----------------------+--------------------------+
                        |
                        v
+--------------------------------------------------+
| 验证评估层                                        |
| 回测收益、风险指标、胜率统计、策略对比             |
+-----------------------+--------------------------+
                        |
                        v
+--------------------------------------------------+
| 运维收尾层                                        |
| 闭盘补充、过期清理、运行日志、异常告警             |
+--------------------------------------------------+
```

## 4. 核心原则

```text
基础数据先于二次计算
        |
        v
二次计算先于策略筛选
        |
        v
策略筛选先于回测验证
        |
        v
闭盘后数据适合放在主交易数据完成后补充
```
