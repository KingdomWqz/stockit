# Stockit

A股选股器：提供股票搜索与 K 线查看功能，数据源为 AKShare。

## Language

**Stock** (股票):
在沪深京交易所上市交易的人民币计价普通股（A股），以六位数字代码唯一标识。
_Avoid_: 个股, 标的, 股票代码（用 code 指代代码本身）

**Market** (市场):
股票所在的证券交易所，分为上海、深圳、北京三所，由代码前缀唯一决定。
_Avoid_: 交易所, 板块

**Active** (在市):
股票当前处于正常上市状态，可被搜索和交易。
_Avoid_: 在交易, 有效, 正常

**Inactive** (退市):
股票已从交易所摘牌，不再上市交易，但历史行情数据保留。
_Avoid_: 停牌（停牌是临时暂停交易，股票仍在市）, 下市
